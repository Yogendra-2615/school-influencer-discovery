# Data sources
Each row was taken from a publicly available speaker/faculty/contributor page via web search; the `url` column
holds that source page (not a LinkedIn URL). Only facts stated on those pages were used; blank = not stated.
Pages: globalcitizenshipfoundation.org, gessdubai.com, wes.eletsonline.com, iscresearch.com, doyoubuzz.com,
lulu.com spotlight, asugsvsummit.com, amrita.edu, ted.com (TEDx event), vega.edu.in, britishcouncil.in, orfonline.org,
sushantuniversity.edu.in, nonviolent-resistance.info.
Last rows (policy/university/peace-studies) are deliberate lower-relevance profiles so ranking has contrast.
